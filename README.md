# La Tela
Sitio estático para venta de telas por metro y cortes de 25 × 25 cm y 50 × 50 cm.

## Publicar en GitHub Pages
1. Crea un repositorio llamado latela en tu cuenta de GitHub.
2. Sube index.html y este README.md a la raíz del repositorio, en la rama main.
3. En Settings > Pages selecciona Deploy from a branch, rama main y carpeta / (root), y guarda.
4. Cuando termine el despliegue, abre el enlace que indique GitHub Pages.

## Editar
Abre index.html, pulsa el lápiz, modifica y confirma con Commit changes.
Los productos de muestra están en la variable products dentro del script.
La selección se guarda localmente en el navegador. No hay pagos, stock ni pedidos reales.
Las fuentes de Google requieren conexión a Internet; hay fuentes alternativas del sistema.
El dominio latela.cl debe configurarse aparte cuando sea tuyo. No se incluye CNAME.
